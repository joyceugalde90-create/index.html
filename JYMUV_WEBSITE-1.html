Lesson 42

Server Management

Objectives

At the end of the lesson, students must be able to:

  1. Define server management and its importance in an organization.
  2. Identify the different functions and responsibilities involved in server management.
  3. Explain the key components of effective server management; and
  4. Demonstrate understanding through participation in class activities and discussion.

What is Server Management?

Server Management refers to the process of monitoring, maintaining, configuring, securing, and optimizing servers to ensure reliable and efficient operation.

Importance of Server Management

  • Ensures system availability
  • Protects data and resources
  • Improves performance
  • Prevents downtime
  • Supports business continuity

Key Responsibilities of a Server Administrator

  • Installing and configuring servers
  • Managing user accounts and permissions
  • Monitoring server performance
  • Implementing security measures
  • Performing backup and recovery
  • Updating software and operating systems
  • Troubleshooting server issues

Types of Servers

  • File Server
  • Web Server
  • Database Server
  • Mail Server
  • Application Server
  • Domain Controller

Key Areas of Server Management

AreaDescription
User ManagementControls user access and permissions
Security ManagementProtects against threats and unauthorized access
Backup ManagementEnsures data recovery in case of failure
Performance MonitoringTracks CPU, RAM, disk, and network usage
MaintenanceUpdates and patches server software
Lesson 43

Server Management Roles and Functions

Server Management Overview

Server management is the process of maintaining, monitoring, and controlling servers to ensure they function properly, securely, and efficiently in a network system.

Types of Servers and Their Functions

1. File Server

Stores and manages files that users can access over a network.

Example: Shared folders in a school or office

Function: Centralized file storage and access control

2. Web Server

Hosts websites and delivers web pages to users through the internet.

Example: Google, school website

Function: Responds to browser requests using HTTP/HTTPS

3. Database Server

Manages and stores structured data for applications.

Example: Enrollment systems, banking systems

Function: Handles queries, updates, and data storage

4. Mail Server

Handles sending, receiving, and storing emails.

Example: Gmail, Outlook servers

Function: Manages email communication (SMTP, IMAP, POP3)

5. Application Server

Runs software applications for users over a network.

Example: Online games, ERP systems

Function: Processes business logic and application services

6. Domain Controller Server

Manages user authentication and access rights in a network.

Example: School login system

Function: Controls user accounts, passwords, and permissions

Lesson 44

Server Management Relationships

Key Relationships in Server Management

1. Server and Client Relationship

A server provides services while clients request and use those services.

Example:

  • Server stores files.
  • Student computers access the files.
Relationship:
Server → Provides Resources
Client → Uses Resources

2. Server and Network Relationship

Servers require network infrastructure to communicate with clients.

Examples:

  • Switches
  • Routers
  • Network cables
  • Wireless access points
Relationship:
Network enables communication between servers and users.

3. Server and Administrator Relationship

The server administrator manages and maintains server operations.

Responsibilities include:

  • User account management
  • Security management
  • Software updates
  • Backup and recovery
  • Performance monitoring
Relationship:
Administrator → Maintains Server
Server → Delivers Services

4. Relationship Among Different Servers

Organizations often use multiple servers working together.

Lesson 45

Network Operating System (NOS)

What is a Network Operating System (NOS)?

A Network Operating System (NOS) is specialized software installed on a server that manages network resources, users, security, and communication among connected devices.

It enables computers to share resources and communicate effectively within a network.

Functions of a Network Operating System

1. User Management

  • Creates and manages user accounts.
  • Controls user permissions and access rights.

2. Resource Sharing

  • Allows sharing of files, folders, printers, and applications.

3. Security Management

  • Protects network resources from unauthorized access.
  • Implements passwords and security policies.

4. Network Administration

  • Monitors and manages network performance.
  • Controls connected devices.

5. Data Backup and Recovery

  • Protects important information through backups.
  • Restores data when needed.

6. Communication Management

  • Enables communication between servers and clients.

Features of a Network Operating System

FeatureDescription
Centralized ManagementControls users and resources from one location
SecurityProtects data and network resources
File SharingAllows users to access shared files
Printer SharingEnables multiple users to use printers
ScalabilitySupports network growth
ReliabilityProvides stable network operations

Examples of Network Operating Systems

Microsoft Windows Server

  • Widely used in schools and businesses.
  • Supports Active Directory and file sharing.

Linux Server

  • Open-source and highly customizable.
  • Popular for web and database servers.

UNIX

  • Known for stability and security.
  • Common in large organizations.

Lesson 46

Windows Server 2022

What is Windows Server 2022?

Windows Server 2022 is a server operating system developed by Microsoft that helps organizations manage networks, users, devices, applications, and data securely and efficiently.

It serves as a platform for hosting services, managing users, sharing resources, and securing network operations.

Main Functions of Windows Server 2022

1. User and Account Management

  • Creates and manages user accounts.
  • Controls user permissions and access rights.

2. File and Printer Sharing

  • Allows users to access shared files and printers.
  • Provides centralized resource management.

3. Network Management

  • Manages network services and connected devices.
  • Supports communication between computers.

4. Security Management

  • Protects systems from unauthorized access.
  • Implements security policies and access controls.

5. Data Storage and Backup

  • Stores organizational data securely.
  • Supports backup and recovery operations.

6. Application Hosting

  • Runs web applications, databases, and network services.

Benefits of Windows Server 2022

  • Improved security features
  • Centralized administration
  • Better performance and reliability
  • Support for virtualization
  • Efficient resource sharing
  • Easier user management
  • Scalable for growing organizations

Common Uses of Windows Server 2022

Government Offices

Businesses

  • Web hosting
